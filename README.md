# Height and Weight Prediction of Students - ML Project

Predict the **Height** and **Weight** of students using Machine Learning regression models.  
This project helps in analyzing student growth patterns and can be used for school health checkups, nutrition planning, and early detection of underweight/obesity.

---

## 📌 Problem Statement
Growth metrics like height and weight are key indicators of student health.  
The goal of this project is to build ML models that can accurately predict a student's height and weight based on features like age, gender, BMI, and other physical/demographic attributes.

---

## 🎯 Key Objectives
- Perform Data Cleaning and Exploratory Data Analysis
- Train and compare multiple Regression models
- Evaluate model performance using standard metrics
- Provide insights for health and fitness analysis in schools

---

## 📊 Dataset
The dataset contains student records with features such as:
- `Age`
- `Gender`
- `Height`  ← Target 1
- `Weight`  ← Target 2
- `BMI`
- `Grade/Class` etc.
